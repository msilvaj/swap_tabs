1) No Edge ou Chrome entre em chrome://extensions
• Ative “Modo do desenvolvedor”.
• Clique em “Carregar sem compactação” e aponte para a pasta.
Aparecerá um ícone cinza na barra.

2) Abra as duas páginas que quer exibir (na mesma janela).
Clique no ícone: ele ficará com a badge “ON” e começará a alternar.
Clique novamente para parar.

Vantagens:
• Não depende de pop-ups; usa a API oficial tabs.update.
• Não precisa instalar nenhum programa externo.
• Pode mudar o intervalo alterando a constante INTERVALO_MS.
